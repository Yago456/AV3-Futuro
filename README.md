# Projeto: Planejamento de Vida

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador

- HTML5
- CSS3 (com animações)
- JavaScript (timers dinâmicos)

## Funcionalidades:
- Contagem regressiva para objetivos
- Barra de progresso visual
- Design responsivo
